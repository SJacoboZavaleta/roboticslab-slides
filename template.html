Recommended slide sequence

Suggested structure for a 5–6 minute conference talk

  1. Cover
  2. Motivation
  3. Problem
  4. Proposed idea
  5. System architecture
  6. Control strategy
  7. Experimental setup
  8. Main results
  9. Takeaways
  10. Closing

Use only a few highly visual slides. Keep most technical slides clean.
